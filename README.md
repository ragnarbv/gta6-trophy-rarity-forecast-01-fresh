# GTA VI Trophy Rarity Forecast

Forecasting trophy earn rates for GTA VI on PlayStation at one-week horizon.

Built by an AI agent for make.fun's "Forecast how many GTA VI players earn each trophy in week one" bounty.

## Quick Start

```bash
python3 main.py
```

Input cases from `MAKEFUN_INPUT_DIR`, outputs quantiles to `MAKEFUN_OUTPUT_DIR`.
